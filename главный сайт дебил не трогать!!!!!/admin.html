🔑 Выдать доступ стримеру

Доступ привязывается к профилю игрока: войти в кабинет сможет только он, даже если другой узнает ключ. Игрок должен быть зарегистрирован и хотя бы раз войти на сайт.

Ссылка нужна для раздела «Стримеры»: когда стример в эфире, нажатие на его карточку ведёт сразу на живую трансляцию, иначе — на канал. Поддерживаются ссылки вида /@имя, /channel/UC…, /c/имя, /user/имя.

🪙 Монеты игроков

Монеты за матчи начисляются автоматически при одобрении отчёта (+10 победа, +2 хедшот, +5/+10/+15 за матчи «в плюсе», +10 эйс). Здесь можно выдать их вручную или включить игроку безлимитный баланс — например, себе, чтобы тестировать магазин.

📞 Контакты и группы

Видно всем на странице «Поддержка». Принимаются ссылки vk.com / vk.ru и chat.whatsapp.com / wa.me (для VK можно просто @имя, для WhatsApp — номер). Пустые поля не показываются.

☁️ Хранилище файлов (видео и фото)

Если видео и жалобы с видео не загружаются — Firebase Storage не включён (нужен тариф Blaze). Бесплатное решение: cloudinary.com → регистрация → Dashboard: скопируй «Cloud name». Затем Settings → Upload → Upload presets → Add preset → Signing mode: Unsigned → Save, скопируй имя пресета. Вставь оба значения сюда — и всё заработает у всех, без правки кода.

📡 Автоопределение эфира YouTube

Чтобы раздел «Стримеры» сам показывал «В ЭФИРЕ», когда у стримера идёт трансляция на YouTube, вставь ключ YouTube Data API v3 (Google Cloud → APIs & Services → Credentials → Create API key; включи «YouTube Data API v3», в ограничениях ключа укажи адрес твоего сайта). Проверка идёт раз в ~2,5 минуты и тратит мало квоты. Без ключа эфир определяется только по открытому кабинету стримера.

🏆 Награды ТОП-3 месяца

17 числа в 00:00 (UTC+6) статистика месяца обнуляется. Игроки ТОП-1/2/3 прошлого месяца автоматически получают эксклюзивные баннер, рамку и анимацию на весь новый месяц (это запускается само, когда ты открываешь админку или одобряешь отчёт). Кнопка ниже пересчитывает награды вручную.

⚡ Система ELO

ELO игрока копится бесконечно и не обнуляется. За победу — +25 плюс +10 за килл и +5 за хедшот; за поражение (в т.ч. ТП) — −10, килы при поражении ELO не поднимают. Числа — в начале блока ELO в admin.js.

♻ Аннуляция матчей и статистики

Выбери игрока — ниже появятся все его матчи, каждая победа и поражение над каждым соперником отдельной строкой. Отметь нужные и нажми «Аннулировать выбранные»: у игрока вернутся назад ELO, победы, поражения, киллы, хедшоты и эйсы этого матча, серия побед пересчитается, запись исчезнет из истории. Командный матч с несколькими соперниками аннулируется целиком. Для полной очистки есть кнопки сброса ниже.

Полный сброс: ELO вернётся к 500, победы, поражения, игры, киллы, хедшоты, эйсы, серии и история станут нулями. Монеты, покупки и профиль не трогаются.

🧹 Общая аннуляция статистики всех игроков

За месяц — у всех игроков и гильдий обнуляются победы, поражения, матчи, киллы, хедшоты и ELO месяца (рейтинг «За месяц» начинается заново). За всё время — полный сброс: ELO всех игроков возвращается к 500, победы, поражения, матчи, киллы, хедшоты, эйсы, серии, история матчей и рейтинг гильдий обнуляются. Монеты, покупки, профили, видео и фото не трогаются. Отменить нельзя.

🗑 Удаление игроков

Для тех, кто зарегистрировался несколько раз или попросил удалить профиль. Удаляется профиль, история матчей и «бронь» имени — после этого можно зарегистрироваться заново под тем же ником. Рейтинг гильдий и опубликованные видео не затрагиваются. Это нельзя отменить.
